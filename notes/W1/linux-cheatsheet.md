# Linux 命令速查表（W1）

> 练习环境：**Git Bash**（你机器上现成的精简 Linux 环境，开始菜单搜 "Git Bash"）。
> 路径写法：Git Bash 里 D 盘写作 `/d/`，如 `cd /d/llm-learning-notes`（仓库已于 11.19 从 `D:\学习资料\` 移到 `D:\` 根目录）。
> 权限相关（chmod/chown）在 Windows 上语义不完整，理解概念即可，W2 连服务器后再实练。

## 1. 导航与查看

| 命令 | 作用 | 常用参数 |
|---|---|---|
| `pwd` | 我在哪（打印当前目录） | — |
| `cd <dir>` | 去哪 | `cd ..` 上级；`cd ~` 家目录；`cd -` 回上一个位置 |
| `ls` | 列出文件 | `-l` 详细；`-a` 含隐藏；`-h` 人类可读大小；`-t` 按时间排序 |
| `cat <file>` | 打印文件全文 | 小文件用 |
| `head -n 20 <file>` | 前 20 行 | `tail -n 20` 则是后 20 行 |
| `less <file>` | 翻页查看大文件 | q 退出，/ 搜索 |
| `which <cmd>` | 某命令的可执行文件在哪 | 排查环境问题时神级有用 |

**`ls -l` 输出逐字段解读（W1 验收考点）：**
```
-rw-r--r--  1  xiaoding  staff  2048  Nov 17 10:30  notes.md
│└┬┘└┬┘└┬┘   │    │        │      │        │           └ 文件名
│ │   │   │   │    │        │      │        └ 修改时间
│ │   │   │   │    │        │      └ 大小(字节)
│ │   │   │   │    │        └ 所属组
│ │   │   │   │    └ 所有者
│ │   │   │   └ 硬链接数
│ │   │   │
│ │   │   └ 其他人权限: r-- 只读
│ │   └ 组权限:     r-- 只读
│ └ 所有者权限:     rw- 可读可写
└ 文件类型: - 普通文件, d 目录, l 软链接
```

**权限数字速算**：r=4, w=2, x=1，相加。
`chmod 755 script.sh` = 所有者 rwx(7)、组 rx(5)、其他人 rx(5)。
脚本要能执行必须有 x 位：`chmod +x script.sh`。

## 2. 搜索与处理

| 命令 | 作用 | 常用参数 |
|---|---|---|
| `grep "关键词" <file>` | 在文件里找行 | `-i` 忽略大小写；`-n` 显示行号；`-r` 递归整个目录 |
| `find <dir> -name "*.py"` | 按名字找文件 | 递归，比资源管理器搜索快 |
| `wc` | 统计 | `wc -l` 数行数 |

## 3. 管道与重定向（本页灵魂）

```bash
命令A | 命令B     # A 的输出作为 B 的输入 —— "积木式拼接"
命令 > 文件        # 输出写入文件（覆盖）
命令 >> 文件       # 输出追加到文件末尾
```

经典组合（每个都亲手跑一遍）：
```bash
ls -la | grep notes          # 文件列表里只看含 notes 的行
grep -r "TODO" notes | wc -l # 整个笔记目录里有几处 TODO
ps aux | grep python         # 进程列表里筛 python 进程（服务器排障必备）
history | tail -20           # 最近敲过的 20 条命令
```

> 为什么重要：你在服务器上跑训练/部署时，"查日志 + 筛错误 + 数行数"全是这套组合拳，
> `tail -f train.log | grep loss` 就是以后盯训练loss的日常。LLM 工程师的 Linux 功底，90% 用在管道上。

## 4. 其他高频

| 命令 | 作用 |
|---|---|
| `mkdir -p a/b/c` | 一次建多层目录 |
| `cp / mv / rm` | 复制 / 移动或改名 / 删除 |
| `ps aux`、`kill <pid>` | 看进程 / 杀进程 |
| `df -h`、`du -sh <dir>` | 磁盘整体 / 某目录占了多大（GPU 服务器上管数据必备） |
| `ssh user@host` | 远程连接（W2 主菜） |
